# Autodesk AutoCAD Certified Professional (ACP) Study Repository

Welcome to my personal learning, documentation, and exam preparation hub for the **AutoCAD for Design and Drafting Professional Certification**. This repository is systematically organized to track my progress, document advanced workflows, and store clean, paraphrased study notes mapped directly to the official certification objectives.

---

##  Certification Objectives & Focus
The primary purpose of this repository is to build a high-quality technical reference library for mastering advanced CAD mechanics, layout design, and drawing configuration. The study path focuses heavily on:
* Structuring efficient drawing logic using advanced layer controls and filters.
* Manipulating user coordinate systems (UCS) for complex layout orientations.
* Maintaining drawing health, project automation, and external design data management.
* Developing production-ready electrical layout schemas and annotations.
