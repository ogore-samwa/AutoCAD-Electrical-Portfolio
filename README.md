##  How I Draw a Hybrid Solar System

A simplified view of the power path I document in my Single Line Diagrams:

```mermaid
flowchart LR
    PV[" PV Array<br/>(strings)"] --> DCI["DC Isolator<br/>+ DC SPD"]
    DCI --> INV["Hybrid Inverter<br/>(MPPT)"]
    BAT["Battery Bank"] <-->|"DC bus + fuse"| INV
    GRID["Grid"] --> ACI["AC Isolator"]
    ACI --> INV
    INV --> DB["Distribution Board<br/>RCD + MCBs + AC SPD"]
    DB --> L1["Lighting"]
    DB --> L2["Ring Main"]
    DB --> L3["Heavy Loads"]
    EARTH["⏚ Earthing / Bonding"] -.-> DB
    EARTH -.-> PV

    style PV fill:#f7b733,stroke:#333,color:#000
    style BAT fill:#2ea44f,stroke:#333,color:#fff
    style INV fill:#0696d7,stroke:#333,color:#fff
    style DB fill:#e51050,stroke:#333,color:#fff
```
